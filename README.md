# 拡張連続性公理 (Extended Continuity Axiom, ECA)  
  
このリポジトリは、著者が独自に構築・検討している数学的理論「拡張連続性公理（Extended Continuity Axiom, ECA）」に関する文書・数式・考察を個人的に管理および公開することを目的としています。  
ECAは現在も発展途上にある研究・考察であり、本リポジトリに収録されている内容は今後の進展によってその文書の定義・内容・記述方法などが変更される可能性があります。  
  
---  
  
## 概要  
  
拡張連続性公理（ECA）は「公理体系を数学的対象として扱うことを出発点の一つとし、公理体系の集合および公理体系間に存在する構造を記述することを目的とした数学的枠組みです。  
ECAでは特定の一つの公理体系のみを対象とするのではなく、複数の公理体系を数学的対象として扱い、それらから構成される集合や構造を考察します。  
例えば連続体仮説（CH）は、ECAの構築における重要な出発点・具体例の一つです。CHが成立する公理体系、CHが成立しない公理体系、さらにCHが独立となる状況などを含め、異なる公理体系を対象化することで、公理体系そのものについてどのような一般的構造を記述・導出できるのかを検討します。  
この観点から、ECAにおける「連続性」は「単に連続量を扱うことだけを意味するもの」ではありません。離散的な構造と連続的な構造の双方を含む評価形式を用いながら、公理体系の集合やその内部構造を記述することを目指しています。  
ECAでは、その構造を扱うための枠組みとしてSolver集合などの概念を導入しています。  
また、ECAでは公理体系に対する構造的な評価を数理的に記述するため、構造整合性、公理分散値、公理の選択・分布に関する量など、複数の評価要素を扱います。しかし、これらはECAそのものを単一の数値へ還元するためのものではなく、公理体系間の構造を記述するための要素として現状は位置付けられています。  
  
---  
  
## ECAの基本的な考え方  
  
ECAでは、数学的対象を一段階上の対象として扱うという考え方を重視します。  
例えば「命題 -> 公理体系 -> 公理体系の集合 -> 公理体系間の構造」というように「ある数学的対象をさらに対象化する」ことで、その対象自身について新たな数学的構造を記述することを考えます。  
この考え方に基づき、ECAでは特定の公理体系に含まれる個々の命題だけではなく、公理体系そのものを対象として扱います。  
したがって、ECAは単にZFCなど既存の公理体系へ新しい公理を追加することを目的としたものではありません。  
より正確には「公理体系を数学的対象として扱うことで、公理体系そのものについてどのような一般的な構造・性質を導出できるのか」という問いを中心的な課題の一つとしています。
