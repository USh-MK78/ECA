\section{序論}

本稿では、ECA における Solver 集合を基礎として、
(A)--(E) において導入された数学的構造を厳密に定式化し、
そこから実際に導出可能な命題を証明する。

Solver 集合を

\begin{equation}
    \Solver
    =
    \left\{
        S
        \mid
        S=(\mathcal A_S,\mathcal R_S)
    \right\}
\end{equation}

とする。

ここで $\mathcal A_S$ は Solver $S$ における公理の選択集合、
$\mathcal R_S$ は推論規則および構成制約の集合である。

また、Solver によって表現される理論を与える写像として

\begin{equation}
    \mathcal T:
    \Solver
    \longrightarrow
    \mathrm{Th}
\end{equation}

を考える。

さらに、ECA において Solver の評価を表す関数として

\begin{equation}
    I:
    \Solver
    \longrightarrow
    [0,1]
\end{equation}

を考える。

本稿ではこれらの既存構造を基礎として、

\begin{equation}
    \Solver
    \xrightarrow{\mathcal G}
    X
    \xrightarrow{\Psi}
    \R
\end{equation}

という一般解の評価構造を構成する。

\section{(A) Solver 集合の数学的構造}
\label{sec:A}

\subsection{A.1 基本構造}

Solver 集合 $\Solver$ に対して、集合族

\begin{equation}
    \mathcal F_{\Solver}
    \subseteq
    \mathcal P(\Solver)
\end{equation}

を導入し、

\begin{equation}
    (\Solver,\mathcal F_{\Solver})
\end{equation}

を可測空間とする。

$\mathcal F_{\Solver}$ は $\sigma$-代数であるため、

\begin{align}
    \varnothing
    &\in
    \mathcal F_{\Solver},
    \\
    A\in\mathcal F_{\Solver}
    &\Longrightarrow
    \Solver\setminus A
    \in
    \mathcal F_{\Solver},
    \\
    A_n\in\mathcal F_{\Solver}
    \quad(n\in\N)
    &\Longrightarrow
    \bigcup_{n=1}^{\infty}A_n
    \in
    \mathcal F_{\Solver}
\end{align}

が成立する。

さらに測度

\begin{equation}
    \mu:
    \mathcal F_{\Solver}
    \longrightarrow
    [0,\infty]
\end{equation}

を導入する。


%------------------------------------------------------------
\subsection{A.2 距離構造}

Solver 集合上の距離を

\begin{equation}
    d_{\Solver}:
    \Solver\times\Solver
    \longrightarrow
    [0,\infty)
\end{equation}

とする。

以下を仮定する：

\begin{align}
    d_{\Solver}(S_1,S_2)&\geq0,
    \\
    d_{\Solver}(S_1,S_2)&=0
    \iff
    S_1=S_2,
    \\
    d_{\Solver}(S_1,S_2)
    &=
    d_{\Solver}(S_2,S_1),
    \\
    d_{\Solver}(S_1,S_3)
    &\leq
    d_{\Solver}(S_1,S_2)
    +
    d_{\Solver}(S_2,S_3).
\end{align}

このとき $(\Solver,d_{\Solver})$ は距離空間である。


%------------------------------------------------------------
\subsection{A.3 ノルム構造}

さらに Solver 集合が線形空間として構成され、

\begin{equation}
    \|\cdot\|_{\Solver}:
    \Solver\longrightarrow[0,\infty)
\end{equation}

がノルムであると仮定する。

距離を

\begin{equation}
    d_{\Solver}(S_1,S_2)
    :=
    \|S_1-S_2\|_{\Solver}
\end{equation}

と定義すれば、$\Solver$ はノルム空間となる。


%------------------------------------------------------------
\subsection{A.4 Cauchy 列}

\begin{definition}[Cauchy 列]
列

\begin{equation}
    (S_n)_{n\in\N}
\end{equation}

が $\Solver$ における Cauchy 列であるとは、

\begin{equation}
    \forall\varepsilon>0,\,
    \exists N\in\N,\,
    \forall m,n\geq N:
    \|S_m-S_n\|_{\Solver}<\varepsilon
\end{equation}

が成立することをいう。
\end{definition}


%------------------------------------------------------------
\subsection{A.5 完備性}

\begin{definition}[完備性]
ノルム空間 $(\Solver,\|\cdot\|_{\Solver})$ が完備であるとは、
任意の Cauchy 列 $(S_n)$ に対して、

\begin{equation}
    \exists S\in\Solver
    \quad
    \text{s.t.}
    \quad
    \|S_n-S\|_{\Solver}
    \longrightarrow0
\end{equation}

が成立することである。
\end{definition}

したがって、

\begin{equation}
    \boxed{
        \text{任意の Cauchy 列が }\Solver\text{ 内で収束}
        \Longleftrightarrow
        \Solver\text{ は Banach 空間}
    }
\end{equation}

である。


%------------------------------------------------------------
\subsection{A.6 非完備の場合}

\begin{proposition}[Cauchy 列による Banach 性の判定]
\label{prop:A-banach}
ノルム空間 $(\Solver,\|\cdot\|_{\Solver})$ に対して、
ある Cauchy 列 $(S_n)$ が存在して

\begin{equation}
    \nexists S\in\Solver
    \quad
    \text{s.t.}
    \quad
    \|S_n-S\|_{\Solver}\to0
\end{equation}

が成立するならば、$\Solver$ は Banach 空間ではない。
\end{proposition}

\begin{proof}
Banach 空間の定義より、Banach 空間では任意の Cauchy 列が
空間内の元へ収束しなければならない。

仮定より $(S_n)$ は Cauchy 列であるにもかかわらず、
その極限となる $S\in\Solver$ が存在しない。

したがって $(\Solver,\|\cdot\|_{\Solver})$ は完備ではない。

ゆえに Banach 空間ではない。
\end{proof}


%------------------------------------------------------------
\subsection{A.7 完備化}

非完備の場合、$\Solver$ の完備化

\begin{equation}
    \widehat{\Solver}
\end{equation}

を考えることができる。

このとき、

\begin{equation}
    \Solver
    \hookrightarrow
    \widehat{\Solver}
\end{equation}

という等長埋め込みを取ることができ、$\widehat{\Solver}$ は Banach
空間となる。

したがって、Solver 集合そのものの完備性が未証明である場合には、

\begin{equation}
    \Solver
    \subseteq
    \widehat{\Solver}
\end{equation}

という関係を明示する必要がある。

\begin{remark}
これは単なる技術的問題ではない。
一般解を $\Solver$ 上に定義するのか、それとも完備化
$\widehat{\Solver}$ 上まで拡張するのかによって、一般解の定義域
そのものが変化するためである。
\end{remark}

\section{(B) 一般評価空間の構成}
\label{sec:B}

\subsection{B.1 評価空間}

Solver 集合の評価を受け取る空間を $X$ とする。

\begin{equation}
    X
\end{equation}

に対して、評価写像

\begin{equation}
    \Phi:
    \Solver
    \longrightarrow
    X
\end{equation}

を考える。

また、一般解を

\begin{equation}
    \mathcal G:
    \Solver
    \longrightarrow
    X
\end{equation}

と定義する。


%------------------------------------------------------------
\subsection{B.2 一般解の構造}

一般解は Solver $S$ に対して

\begin{equation}
    S
    \longmapsto
    \mathcal G(S)
\end{equation}

という評価空間上の元を与える。

したがって、

\begin{equation}
    \boxed{
        \mathcal G:\Solver\to X
    }
\end{equation}

を一般解の基本形とする。


%------------------------------------------------------------
\subsection{B.3 一般解の存在に必要な条件}

一般解を構成するためには、少なくとも次の写像が定義されている
必要がある：

\begin{equation}
    \Phi:\Solver\to X.
\end{equation}

さらに、$\Phi$ が Solver の評価構造を表すという意味で
許容される写像であることを要求する。

ここで重要なのは、

\begin{equation}
    \Phi:\Solver\to X
\end{equation}

が存在することと、

\begin{equation}
    \Phi
\end{equation}

が ECA の要求する一般解となることは同値ではないことである。

後者には、Solver 構造の保存条件および評価条件が必要となる。


%------------------------------------------------------------
\subsection{B.4 最終評価写像}

評価空間 $X$ から実数値評価を取り出す写像を

\begin{equation}
    \Psi:
    X
    \longrightarrow
    \R
\end{equation}

とする。

このとき、

\begin{equation}
    g
    :=
    \Psi\circ\mathcal G
\end{equation}

によって

\begin{equation}
    g:\Solver\to\R
\end{equation}

を得る。

すなわち、

\begin{equation}
    \boxed{
        g(S)
        =
        \Psi(\mathcal G(S))
    }
\end{equation}

である。


%------------------------------------------------------------
\subsection{B.5 ECA の既存評価量との接続}

ECA において既に

\begin{equation}
    B,\qquad I,\qquad K
\end{equation}

を用いた評価式が定義されている。

離散的表現では、

\begin{equation}
    T_{\mathrm{overlay}}
    =
    \frac{1}{N}
    \sum_{j=1}^{N}
    B_jI_jK_j
\end{equation}

が与えられ、連続的表現では

\begin{equation}
    T_{\mathrm{overlay}}
    =
    \int
    B(x)I(x)K(x)\,dx
\end{equation}

が与えられる。

したがって、一般評価空間 $X$ は、少なくともこれらの評価量を
表現可能な空間として構成される必要がある。

ただし、この式から直ちに

\begin{equation}
    \mathcal G:\Solver\to X
\end{equation}

の存在が証明されるわけではない。

\section{(C) 評価関数の測度論的性質}
\label{sec:C}

\subsection{C.1 評価関数}

(B) より、

\begin{equation}
    g
    =
    \Psi\circ\mathcal G
\end{equation}

とする。

ここで、

\begin{equation}
    g:
    \Solver\to\R
\end{equation}

である。


%------------------------------------------------------------
\subsection{C.2 非負性}

\begin{proposition}[非負性]
\label{prop:C-nonnegative}
もし

\begin{equation}
    \Psi(X)\subseteq[0,\infty)
\end{equation}

ならば、

\begin{equation}
    g(S)\geq0
    \qquad
    (\forall S\in\Solver)
\end{equation}

が成立する。
\end{proposition}

\begin{proof}
任意の $S\in\Solver$ を取る。

(B) より、

\begin{equation}
    \mathcal G(S)\in X
\end{equation}

である。

仮定より

\begin{equation}
    \Psi(\mathcal G(S))\in[0,\infty)
\end{equation}

である。

一方、

\begin{equation}
    g(S)
    =
    \Psi(\mathcal G(S))
\end{equation}

だから、

\begin{equation}
    g(S)\geq0
\end{equation}

を得る。

$S$ は任意であるから、

\begin{equation}
    \forall S\in\Solver,\quad g(S)\geq0.
\end{equation}

\end{proof}


%------------------------------------------------------------
\subsection{C.3 積による評価の場合}

特に、

\begin{equation}
    \Psi(B,I,K)=BIK
\end{equation}

であり、

\begin{equation}
    B,I,K\in[0,1]
\end{equation}

ならば、

\begin{equation}
    0\leq BIK\leq1
\end{equation}

である。

したがって、

\begin{proposition}
\label{prop:C-BIK}
\begin{equation}
    B,I,K\in[0,1]
\end{equation}

ならば、

\begin{equation}
    \Psi(B,I,K)=BIK
\end{equation}

によって定義される評価は非負である。
\end{proposition}

\begin{proof}
$B,I,K\in[0,1]$ なので、

\begin{equation}
    B\geq0,\qquad
    I\geq0,\qquad
    K\geq0.
\end{equation}

したがって積の非負性より、

\begin{equation}
    BIK\geq0.
\end{equation}

また、

\begin{equation}
    B\leq1,\qquad
    I\leq1,\qquad
    K\leq1
\end{equation}

なので、

\begin{equation}
    BIK\leq1.
\end{equation}

ゆえに

\begin{equation}
    0\leq BIK\leq1.
\end{equation}
\end{proof}


%------------------------------------------------------------
\subsection{C.4 可測性}

$\Solver$ 上の $\sigma$-代数を $\mathcal F_{\Solver}$ とする。

\begin{proposition}[合成写像による可測性]
\label{prop:C-measurable}
次を仮定する：

\begin{enumerate}
    \item
    \[
        \mathcal G:
        (\Solver,\mathcal F_{\Solver})
        \to
        (X,\mathcal F_X)
    \]
    が可測である。

    \item
    \[
        \Psi:
        (X,\mathcal F_X)
        \to
        (\R,\Borel)
    \]
    が可測である。
\end{enumerate}

このとき、

\begin{equation}
    g=\Psi\circ\mathcal G
\end{equation}

は可測である。
\end{proposition}

\begin{proof}
任意の Borel 集合

\begin{equation}
    A\in\Borel
\end{equation}

を取る。

$\Psi$ の可測性より、

\begin{equation}
    \Psi^{-1}(A)
    \in
    \mathcal F_X.
\end{equation}

さらに $\mathcal G$ の可測性より、

\begin{equation}
    \mathcal G^{-1}
    \left(
        \Psi^{-1}(A)
    \right)
    \in
    \mathcal F_{\Solver}.
\end{equation}

一方、

\begin{align}
    g^{-1}(A)
    &=
    (\Psi\circ\mathcal G)^{-1}(A)
    \\
    &=
    \mathcal G^{-1}
    \left(
        \Psi^{-1}(A)
    \right).
\end{align}

したがって、

\begin{equation}
    g^{-1}(A)
    \in
    \mathcal F_{\Solver}.
\end{equation}

$A$ は任意だったので $g$ は可測である。
\end{proof}


%------------------------------------------------------------
\subsection{C.5 正規化可能性}

評価関数 $g$ に対して、

\begin{equation}
    Z
    :=
    \int_{\Solver}
    g(S)\,d\mu(S)
\end{equation}

を考える。

\begin{proposition}[正規化]
\label{prop:C-normalization}
$g$ が非負可測関数であり、

\begin{equation}
    0<Z<\infty
\end{equation}

を満たすならば、

\begin{equation}
    \widehat g(S)
    :=
    \frac{g(S)}{Z}
\end{equation}

は正規化され、

\begin{equation}
    \int_{\Solver}
    \widehat g(S)\,d\mu(S)
    =
    1
\end{equation}

を満たす。
\end{proposition}

\begin{proof}
$Z>0$ かつ $Z<\infty$ なので、

\begin{equation}
    \frac1Z
\end{equation}

は有限の正数である。

測度の積分の線形性から、

\begin{align}
    \int_{\Solver}
    \widehat g(S)\,d\mu(S)
    &=
    \int_{\Solver}
    \frac{g(S)}{Z}\,d\mu(S)
    \\
    &=
    \frac1Z
    \int_{\Solver}
    g(S)\,d\mu(S)
    \\
    &=
    \frac{Z}{Z}
    \\
    &=1.
\end{align}

よって命題が成立する。
\end{proof}


%------------------------------------------------------------
\subsection{C.6 (A)--(B) から (C) への依存}

以上より、

\begin{equation}
    \mathcal G:\Solver\to X
\end{equation}

が可測であり、

\begin{equation}
    \Psi:X\to\R
\end{equation}

が可測ならば、

\begin{equation}
    g=\Psi\circ\mathcal G
\end{equation}

も可測となる。

さらに、

\begin{equation}
    \Psi(X)\subseteq[0,\infty)
\end{equation}

ならば $g$ は非負であり、

\begin{equation}
    0<
    \int_{\Solver}g\,d\mu
    <\infty
\end{equation}

ならば正規化可能である。

したがって、

\begin{equation}
\boxed{
\begin{array}{c}
\mathcal G\text{ の可測性}\\
+
\\
\Psi\text{ の可測性}
\\[2mm]
\Downarrow
\\[2mm]
g=\Psi\circ\mathcal G\text{ の可測性}
\end{array}
}
\end{equation}

という構造が得られる。

\section{(D) 一般解の存在}
\label{sec:D}

\subsection{D.1 一般解存在命題}

一般解の存在を次で定式化する。

\begin{definition}[一般解の存在]
評価空間 $X$ に対して、

\begin{equation}
    \exists\,
    \mathcal G:
    \Solver\to X
\end{equation}

が成立するとき、Solver 集合上に一般解が存在するとする。
\end{definition}


%------------------------------------------------------------
\subsection{D.2 構成による存在}

評価写像

\begin{equation}
    \Phi:\Solver\to X
\end{equation}

が既に定義されており、その値が全ての $S\in\Solver$ に対して
$X$ に属するならば、$\Phi$ 自体が一般解を与える。

\begin{proposition}[評価写像による一般解の存在]
\label{prop:D-existence}
写像

\begin{equation}
    \Phi:\Solver\to X
\end{equation}

が存在するならば、

\begin{equation}
    \mathcal G:=\Phi
\end{equation}

によって一般解

\begin{equation}
    \mathcal G:\Solver\to X
\end{equation}

が存在する。
\end{proposition}

\begin{proof}
$\Phi$ は仮定により $\Solver$ の全ての元に対して定義され、
その値域は $X$ に含まれる。

したがって、

\begin{equation}
    \mathcal G:=\Phi
\end{equation}

と置けば、

\begin{equation}
    \mathcal G:\Solver\to X
\end{equation}

が成立する。

ゆえに一般解が存在する。
\end{proof}


%------------------------------------------------------------
\subsection{D.3 一般解存在に必要な構成条件}

しかし、命題~\ref{prop:D-existence} は
「$\Phi$ が存在する」ことを仮定している。

したがって、ECA の一般解存在を完全に証明するためには、

\begin{equation}
    \boxed{
        \text{ECA の既存定義}
        \Longrightarrow
        \exists\Phi:\Solver\to X
    }
\end{equation}

を別途示す必要がある。

この implication がまだ証明されていない場合、

\begin{equation}
    \exists\mathcal G:\Solver\to X
\end{equation}

を無条件の定理として宣言することはできない。

この点は厳密性の観点から重要である。


%------------------------------------------------------------
\subsection{D.4 Banach 性を仮定した場合}

もし (A) において

\begin{equation}
    (\Solver,\|\cdot\|_{\Solver})
\end{equation}

が Banach 空間であることが証明され、さらに評価写像

\begin{equation}
    \Phi:
    \Solver\to X
\end{equation}

が連続または適切な極限保存性を持つならば、
Cauchy 列の極限を通じて一般解の存在を構成できる可能性がある。

具体的には、

\begin{equation}
    S_n\to S
\end{equation}

に対して

\begin{equation}
    \Phi(S_n)\to x
\end{equation}

となる $x\in X$ を示し、

\begin{equation}
    \mathcal G(S):=x
\end{equation}

と定義する構成が考えられる。

ただし、この議論には $X$ の完備性または $\Phi$ の像が閉集合である
ことなどの追加条件が必要であり、現段階ではこれを一般定理として
採用しない。

\section{(E) Solver 構造に基づく一般解の一意性}
\label{sec:E}

\subsection{E.1 Solver 同型}

二つの Solver 集合

\begin{equation}
    \Solver_1,\qquad\Solver_2
\end{equation}

を考える。

Solver 同型を

\begin{equation}
    T:
    \Solver_1
    \overset{\sim}{\longrightarrow}
    \Solver_2
\end{equation}

とする。

ここで $T$ は単なる集合論的全単射ではなく、
Solver に付随する構造を保存する写像である。


%------------------------------------------------------------
\subsection{E.2 一般解の対応}

各 Solver 集合について、

\begin{equation}
    \mathcal G_1:
    \Solver_1\to X_1,
    \qquad
    \mathcal G_2:
    \Solver_2\to X_2
\end{equation}

を考える。

まず評価空間が同一の場合、

\begin{equation}
    X_1=X_2=X
\end{equation}

と仮定する。


%------------------------------------------------------------
\subsection{E.3 強い一意性}

\begin{definition}[Solver 構造に基づく一般解の一意性]
Solver 同型

\begin{equation}
    T:
    \Solver_1
    \overset{\sim}{\longrightarrow}
    \Solver_2
\end{equation}

に対して、

\begin{equation}
    \boxed{
        \mathcal G_2\circ T
        =
        \mathcal G_1
    }
    \label{eq:E-strong-uniqueness}
\end{equation}

が成立するとき、$\mathcal G_1,\mathcal G_2$ は Solver 構造に関して
一意に対応するとする。
\end{definition}


%------------------------------------------------------------
\subsection{E.4 一意性の証明}

\begin{theorem}[Solver 構造に基づく一般解の一意性]
\label{thm:E-uniqueness}
$T:\Solver_1\overset{\sim}{\to}\Solver_2$ が Solver 同型であり、
二つの一般解が Solver 同型に対して

\begin{equation}
    \mathcal G_2\circ T
    =
    \mathcal G_1
\end{equation}

を満たすならば、$\mathcal G_1$ と $\mathcal G_2$ は同一の
Solver 評価構造を異なる Solver 表現上で与える。
\end{theorem}

\begin{proof}
任意の $S\in\Solver_1$ を取る。

可換性の仮定より、

\begin{equation}
    \mathcal G_2(T(S))
    =
    \mathcal G_1(S)
\end{equation}

が成立する。

したがって、$T$ によって対応する Solver 元は、
一般解によって同一の評価空間上の値を与えられる。

$S$ は任意であるため、

\begin{equation}
    \forall S\in\Solver_1,\quad
    \mathcal G_2(T(S))
    =
    \mathcal G_1(S).
\end{equation}

ゆえに二つの一般解は Solver 同型によって完全に対応する。
\end{proof}


%------------------------------------------------------------
\subsection{E.5 評価空間が異なる場合}

一般には、

\begin{equation}
    X_1\neq X_2
\end{equation}

である可能性がある。

この場合、評価空間間の同型

\begin{equation}
    U:
    X_1
    \overset{\sim}{\longrightarrow}
    X_2
\end{equation}

を考える。

一般解の対応条件を

\begin{equation}
    \boxed{
        U\circ\mathcal G_1
        =
        \mathcal G_2\circ T
    }
    \label{eq:E-general-commutativity}
\end{equation}

とする。


%------------------------------------------------------------
\subsection{E.6 評価写像が異なる場合}

二つの評価写像

\begin{equation}
    \Phi_1:\Solver_1\to X_1,
    \qquad
    \Phi_2:\Solver_2\to X_2
\end{equation}

を考える。

Solver 同型 $T$ と評価空間同型 $U$ が

\begin{equation}
    U\circ\Phi_1
    =
    \Phi_2\circ T
\end{equation}

を満たすならば、評価写像の具体的表現が異なっていても、
Solver の構造に対して同一の評価構造を与える。


%------------------------------------------------------------
\subsection{E.7 Representation Independence}

\begin{definition}[Representation Independence]
二つの Solver 表現

\begin{equation}
    \Phi_1:\Solver_1\to X_1,
    \qquad
    \Phi_2:\Solver_2\to X_2
\end{equation}

が Solver 同型 $T$ および評価空間同型 $U$ によって

\begin{equation}
    U\circ\Phi_1
    =
    \Phi_2\circ T
\end{equation}

を満たすとき、二つの表現は Representation Independent であるという。
\end{definition}

ここで重要なのは、

\begin{equation}
    X_1\cong X_2
\end{equation}

という事実だけでは Representation Independence を意味しないことで
ある。

必要なのは、

\begin{equation}
    \boxed{
        U\circ\Phi_1
        =
        \Phi_2\circ T
    }
\end{equation}

という評価構造を保存する可換性である。


%------------------------------------------------------------
\subsection{E.8 最終評価の不変性}

最終評価写像を

\begin{equation}
    \Psi_1:X_1\to\R,
    \qquad
    \Psi_2:X_2\to\R
\end{equation}

とする。

さらに、

\begin{equation}
    \Psi_2\circ U
    =
    \Psi_1
\end{equation}

を仮定する。

\begin{theorem}[Representation Independence による最終評価の不変性]
\label{thm:E-final-invariance}
次を仮定する：

\begin{align}
    U\circ\mathcal G_1
    &=
    \mathcal G_2\circ T,
    \\
    \Psi_2\circ U
    &=
    \Psi_1.
\end{align}

このとき、

\begin{equation}
    g_1
    :=
    \Psi_1\circ\mathcal G_1,
    \qquad
    g_2
    :=
    \Psi_2\circ\mathcal G_2
\end{equation}

に対して、

\begin{equation}
    \boxed{
        g_2\circ T
        =
        g_1
    }
\end{equation}

が成立する。
\end{theorem}

\begin{proof}
合成写像の結合則から、

\begin{align}
    g_2\circ T
    &=
    (\Psi_2\circ\mathcal G_2)\circ T
    \\
    &=
    \Psi_2\circ
    (\mathcal G_2\circ T).
\end{align}

仮定

\begin{equation}
    \mathcal G_2\circ T
    =
    U\circ\mathcal G_1
\end{equation}

より、

\begin{align}
    g_2\circ T
    &=
    \Psi_2\circ
    U\circ
    \mathcal G_1.
\end{align}

さらに、

\begin{equation}
    \Psi_2\circ U
    =
    \Psi_1
\end{equation}

なので、

\begin{align}
    g_2\circ T
    &=
    \Psi_1\circ\mathcal G_1
    \\
    &=
    g_1.
\end{align}

したがって、

\begin{equation}
    g_2\circ T=g_1
\end{equation}

が成立する。
\end{proof}


%------------------------------------------------------------
\subsection{E.9 一意性の意味}

ここでいう一般解の一意性は、

\begin{equation}
    \mathcal G_1=\mathcal G_2
\end{equation}

という文字通りの等式を意味しない。

異なる Solver 表現に対して

\begin{equation}
    \Solver_1\neq\Solver_2
\end{equation}

であることも許される。

重要なのは Solver 同型

\begin{equation}
    T:\Solver_1\overset{\sim}{\to}\Solver_2
\end{equation}

および評価空間同型

\begin{equation}
    U:X_1\overset{\sim}{\to}X_2
\end{equation}

によって、

\begin{equation}
    U\circ\mathcal G_1
    =
    \mathcal G_2\circ T
\end{equation}

が成立することである。

したがって、ここでいう一意性は

\begin{equation}
\boxed{
\text{表現そのものの一意性ではなく、
Solver 構造に対する一般解の対応の一意性}
}
\end{equation}

である。

\subsection{統合命題}

\begin{theorem}[Solver 評価構造の基本定理]
\label{thm:basic}
以下を仮定する：

\begin{enumerate}
    \item
    $(\Solver,\mathcal F_{\Solver},\mu)$ が測度空間である。

    \item
    $\Solver$ がノルム空間であり、必要に応じて Banach 性が証明されて
    いる。

    \item
    一般解
    \[
        \mathcal G:\Solver\to X
    \]
    が存在する。

    \item
    $\mathcal G$ および
    \[
        \Psi:X\to\R
    \]
    が可測である。

    \item
    \[
        \Psi(X)\subseteq[0,\infty).
    \]

    \item
    \[
        0<
        \int_{\Solver}
        (\Psi\circ\mathcal G)(S)
        \,d\mu(S)
        <\infty.
    \]
\end{enumerate}

このとき、

\begin{equation}
    g=\Psi\circ\mathcal G
\end{equation}

は非負可測関数であり、正規化関数

\begin{equation}
    \widehat g
    =
    \frac{g}
    {\displaystyle\int_{\Solver}g\,d\mu}
\end{equation}

が存在し、

\begin{equation}
    \int_{\Solver}
    \widehat g\,d\mu
    =
    1
\end{equation}

を満たす。
\end{theorem}

\begin{proof}
命題~\ref{prop:C-nonnegative} より、$\Psi(X)\subseteq[0,\infty)$
から

\begin{equation}
    g(S)\geq0
\end{equation}

が任意の $S\in\Solver$ に対して成立する。

また、命題~\ref{prop:C-measurable} より、
$\mathcal G$ と $\Psi$ の可測性から

\begin{equation}
    g=\Psi\circ\mathcal G
\end{equation}

は可測である。

さらに仮定より

\begin{equation}
    0<
    \int_{\Solver}g\,d\mu
    <\infty.
\end{equation}

したがって命題~\ref{prop:C-normalization} を適用でき、

\begin{equation}
    \widehat g
    =
    \frac{g}
    {\displaystyle\int_{\Solver}g\,d\mu}
\end{equation}

が定義できる。

そして、

\begin{equation}
    \int_{\Solver}\widehat g\,d\mu=1
\end{equation}

を得る。
\end{proof}

\section{(F) 正規化評価と極限構造の厳密証明}

\subsection{F.1 前提}

(A)--(E) において構成された Solver 集合
$\mathcal{S}$、評価空間 $X$、公理選択空間 $I$、
可測族 $\Sigma$ および測度 $\mu$ を考える。

Solver 集合上の評価に用いる重み関数を
\[
w:S\to[0,\infty)
\]
とし、可測集合 $i\in\Sigma$ に対して非正規化測度を

\[
\widetilde{\mu}(i)
:=
W(i)
:=
\sum_{a\in i}w(a)
\]

と定義する。

連続的な場合には、これを

\[
\widetilde{\mu}(i)
=
\int_S \mathbf{1}_i(s)w(s)\,d\nu(s)
\]

と解釈する。

ここで $\nu$ は Solver 集合上の基準測度であり、
離散的な場合には数え上げ測度として扱うことができる。

(A)--(D) により、評価対象は可測構造の上に置かれている。
したがって、以下では少なくとも

\[
w\geq0,
\qquad
i\in\Sigma
\]

を仮定する。

\subsection{F.2 正規化定数}

可測集合族 $\Sigma$ に対して

\[
Z
:=
\sup_{j\in\Sigma}\widetilde{\mu}(j)
\]

と置く。

特に

\[
0<Z<\infty
\]

が成立する場合、正規化評価

\[
\mu(i)
:=
\frac{\widetilde{\mu}(i)}{Z}
\qquad(i\in\Sigma)
\]

を定義することができる。

\subsection{命題 F.1（正規化評価の存在）}

\[
0<Z<\infty
\]

を仮定する。このとき

\[
\mu:\Sigma\to[0,1]
\]

は well-defined であり、

\[
0\leq\mu(i)\leq1
\]

が任意の $i\in\Sigma$ に対して成立する。

\subsection*{証明}

$w\geq0$ であるから、

\[
\widetilde{\mu}(i)\geq0
\]

である。

また $Z$ の定義より

\[
\widetilde{\mu}(i)\leq Z
\]

である。

したがって $0<Z<\infty$ より、

\[
0
\leq
\frac{\widetilde{\mu}(i)}{Z}
\leq
1.
\]

よって

\[
\mu(i)\in[0,1]
\]

であり、$\mu$ は $\Sigma$ 上で well-defined である。
\hfill$\square$

\subsection{命題 F.2（全体正規化）}

$\Sigma$ 上の全体正規化が可能であり、さらにある
$i_0\in\Sigma$ に対して

\[
\widetilde{\mu}(i_0)=Z
\]

が成立するとする。このとき

\[
\mu(i_0)=1.
\]

\subsection*{証明}

定義より

\[
\mu(i_0)
=
\frac{\widetilde{\mu}(i_0)}{Z}
=
\frac{Z}{Z}
=
1.
\]

したがって正規化された測度は最大値 $1$ を取る。
\hfill$\square$

\subsection{F.3 局所正規化}

全体の正規化定数が有限でない場合でも、
可測部分族

\[
\Sigma_0\subseteq\Sigma
\]

について

\[
0<
Z_0
:=
\sup_{j\in\Sigma_0}\widetilde{\mu}(j)
<\infty
\]

が成立するならば、

\[
\mu_0(i)
:=
\frac{\widetilde{\mu}(i)}{Z_0},
\qquad
i\in\Sigma_0
\]

によって局所正規化を行うことができる。

\subsection{命題 F.3（局所正規化の存在）}

上記の条件を満たす $\Sigma_0$ に対して、

\[
\mu_0:\Sigma_0\to[0,1]
\]

が well-defined であり、

\[
0\leq\mu_0(i)\leq1
\]

が成立する。

\subsection*{証明}

命題 F.1 と同様に、

\[
0\leq
\widetilde{\mu}(i)
\leq
Z_0
\]

であるから、

\[
0
\leq
\frac{\widetilde{\mu}(i)}{Z_0}
\leq1.
\]

したがって

\[
\mu_0(i)\in[0,1].
\]

\hfill$\square$

\subsection{F.4 離散評価と連続評価}

Solver 集合が有限または可算の場合、

\[
\widetilde{\mu}(i)
=
\sum_{a\in i}w(a)
\]

である。

一方、Solver 集合が可測空間

\[
(S,\Sigma,\nu)
\]

として与えられる場合には、

\[
\widetilde{\mu}(i)
=
\int_S\mathbf{1}_i(s)w(s)\,d\nu(s)
\]

である。

ここで

\[
w\geq0
\]

であるから、いずれの場合にも

\[
\widetilde{\mu}(i)\geq0
\]

が成立する。

さらに、$w$ が可測であり、

\[
\int_S w(s)\,d\nu(s)<\infty
\]

であれば、正規化定数

\[
Z
=
\int_Sw(s)\,d\nu(s)
\]

は有限となる。

従って、

\[
\mu(i)
=
\frac{
\int_S\mathbf{1}_i(s)w(s)\,d\nu(s)
}{
\int_Sw(s)\,d\nu(s)
}
\]

によって連続形式の正規化評価が得られる。

\subsection{命題 F.4（離散形式から連続形式への整合性）}

離散 Solver 集合を細分化して得られる近似列
$\{S_n\}_{n\in\mathbb{N}}$ に対し、その評価がリーマン和

\[
T_n
=
\sum_{k=1}^{N_n}
f(x_{n,k})\Delta x_{n,k}
\]

として表され、$f$ が可積分であるとする。

このとき、通常の積分論におけるリーマン和の収束条件が
成立すれば、

\[
\lim_{n\to\infty}T_n
=
\int f(x)\,dx
\]

が成立する。

\subsection*{証明}

これはリーマン積分の定義および収束定理から従う。

したがって、Solver 集合上の離散評価を適切な分割に基づく
リーマン和として構成できる場合には、その極限として
連続形式を得ることができる。
\hfill$\square$

\subsection{F.5 極限に関する存在命題}

以下の二つの存在命題を仮定する。

\paragraph{存在命題 F-A}

Solver 集合の離散近似列
$\{S_n\}$ に対して、評価値列
$\{T_n\}$ が存在し、

\[
T_n
=
\sum_{k=1}^{N_n}
B_{n,k}I_{n,k}K_{n,k}
\Delta x_{n,k}
\]

と表される。

\paragraph{存在命題 F-B}

上記の列が適切な可積分関数

\[
f(x)=B(x)I(x)K(x)
\]

に収束し、かつリーマン和の収束条件を満たすならば、

\[
\lim_{n\to\infty}T_n
=
\int B(x)I(x)K(x)\,dx.
\]

これらは、現段階では ECA の Solver 集合一般について
証明された定理ではなく、後続の理論構成において使用する
存在命題として扱う。

\subsection{F.6 論考：Solver 集合における極限の成立可能性}

ECA の既存定式化では、離散形式として

\[
T_{\mathrm{overlay}}
=
\frac{1}{N}
\sum_{j=1}^{N}B_jI_jK_j
\]

が与えられ、連続形式として

\[
T_{\mathrm{overlay}}
=
\int B(x)I(x)K(x)\,dx
\]

が与えられている。

したがって、離散形式と連続形式との対応は、
単なる記号上の類似ではなく、離散評価を適切な重み付き和として
構成し、その極限を積分として解釈することによって
数学的に位置付けられる。

ただし、

\[
\lim_{n\to\infty}
T_n
=
\int BIK\,d\nu
\]

が ECA の任意の Solver 集合について必ず成立することは、
現時点では証明されていない。

この問題には、少なくとも

\[
B,I,K\text{ の可測性},
\]

\[
BIK\in L^1(\nu),
\]

および離散近似列が連続評価へ収束するための
近似構造が必要である。

したがって、この点は本節の定理として断定せず、
ECA における離散形式と連続形式の対応可能性についての
論考として位置付ける。

\section{(G) 一般解 $\mathcal{G}$ の評価写像としての厳密証明}

\subsection{G.1 一般解の定義}

(A)--(F) により構成された Solver 集合を $\mathcal{S}$、
評価空間を $X$ とする。

一般解を

\[
\mathcal{G}:\mathcal{S}\longrightarrow X
\]

と定義する。

各 Solver $s\in\mathcal{S}$ に対して

\[
\mathcal{G}(s)
\]

は、$s$ が定める公理的・評価的条件のもとで得られる
一般化された評価結果を表す。

特に、個々の Solver に依存する表現そのものではなく、
(A)--(E) において確立された評価空間の構造を通して
比較可能な値として扱う。

\subsection{命題 G.1（一般解の well-defined 性）}

各 $s\in\mathcal{S}$ に対して評価

\[
\mathcal{G}(s)\in X
\]

が一意に定まるならば、

\[
\mathcal{G}:\mathcal{S}\to X
\]

は well-defined な写像である。

\subsection*{証明}

写像の定義より、任意の $s\in\mathcal{S}$ に対して
$\mathcal{G}(s)$ がただ一つ存在し、かつ

\[
\mathcal{G}(s)\in X
\]

であることを示せばよい。

仮定より各 $s$ に対する評価値は一意であるから、

\[
s\mapsto\mathcal{G}(s)
\]

は一意的な対応を定める。

したがって

\[
\mathcal{G}:\mathcal{S}\to X
\]

は well-defined である。
\hfill$\square$

\subsection{G.2 評価写像との関係}

Solver $s$ が評価写像

\[
E_s:\mathcal{A}_s\to X
\]

を持つとする。

(A)--(E) において示された評価空間の共通構造を用いることで、
個々の $E_s$ によって得られる結果を共通の空間 $X$ に
配置できる。

したがって一般解は概念的に

\[
\mathcal{G}(s)
=
E_s(\alpha_s)
\]

という形で表される。

ここで $\alpha_s$ は Solver $s$ において評価対象となる
適切な入力または解を表す。

\subsection{命題 G.2（評価空間への共通埋込み）}

各 $s\in\mathcal{S}$ について

\[
E_s(\alpha_s)\in X
\]

が成立するならば、

\[
\mathcal{G}(s):=E_s(\alpha_s)
\]

によって

\[
\mathcal{G}:\mathcal{S}\to X
\]

を構成できる。

\subsection*{証明}

任意の $s\in\mathcal{S}$ に対して仮定より

\[
E_s(\alpha_s)\in X.
\]

したがって

\[
\mathcal{G}(s):=E_s(\alpha_s)
\]

は $X$ の元を与える。

さらに各 $s$ に対して $\alpha_s$ および
$E_s(\alpha_s)$ が一意ならば、$\mathcal{G}$ は一意的に定まる。

よって

\[
\mathcal{G}:\mathcal{S}\to X
\]

が得られる。
\hfill$\square$

\subsection{G.3 Solver 同型に対する一般解の不変性}

Solver $s_1,s_2\in\mathcal{S}$ に対し、

\[
T:s_1\longrightarrow s_2
\]

が Solver 同型であるとする。

また、$X$ 上の対応する同型写像を

\[
\widehat{T}:X\longrightarrow X
\]

とする。

評価写像が $T$ と整合するとは、

\[
\widehat{T}\circ\mathcal{G}_{s_1}
=
\mathcal{G}_{s_2}\circ T
\]

が成立することと定義する。

ここで

\[
\mathcal{G}_{s_i}
\]

は各 Solver 上に制限された一般解を表す。

\subsection{定理 G.3（Solver 同型に対する一般解の自然性）}

上記の可換関係が成立するとき、

\[
\widehat{T}
\bigl(
\mathcal{G}_{s_1}(s)
\bigr)
=
\mathcal{G}_{s_2}(T(s))
\]

が任意の $s\in s_1$ に対して成立する。

\subsection*{証明}

仮定より

\[
\widehat{T}\circ\mathcal{G}_{s_1}
=
\mathcal{G}_{s_2}\circ T.
\]

任意の $s\in s_1$ にこれを適用すると、

\[
(\widehat{T}\circ\mathcal{G}_{s_1})(s)
=
(\mathcal{G}_{s_2}\circ T)(s).
\]

合成写像の定義より、

\[
\widehat{T}
\left(
\mathcal{G}_{s_1}(s)
\right)
=
\mathcal{G}_{s_2}(T(s)).
\]

従って一般解は Solver 同型による表現の変更と整合する。
\hfill$\square$

\subsection{G.4 (A)--(E) との関係}

(A)--(E) において構成された位相的・測度論的・評価論的構造に
より、一般解 $\mathcal{G}$ の値を共通の評価空間 $X$ に
配置するための基盤が与えられる。

特に、(F) によって正規化された評価が

\[
\mu(i)\in[0,1]
\]

として扱える場合、$\mathcal{G}$ の一部または全体を
そのような正規化された評価空間上の写像として構成できる。

したがって、

\[
\mathcal{S}
\overset{\mathcal{G}}{\longrightarrow}
X
\]

という構造は、(A)--(F) において構成された数学的対象を
統合する写像として位置付けられる。

\section{(H) 中間Solverの厳密な定義と構造}

\subsection{H.1 基本設定}

本節では、これまでに定義された Solver 集合
\[
\mathcal{S}
\]
および一般解写像
\[
\mathcal{G}:\mathcal{S}\longrightarrow X
\]
を前提とし、Solver の内部に離散的評価構造と連続的評価構造が
同時に存在する場合を厳密に定式化する。

Solver 集合は

\[
\mathcal{S}
=
\left\{
s\mid
s=(\mathcal{A}_s,\mathcal{R}_s)
\right\}
\]

とする。

ここで、

\[
\mathcal{A}_s
\]

は Solver $s$ において採用される公理の選択集合、

\[
\mathcal{R}_s
\]

は推論規則および構成制約の集合を表す。

また、Solver $s$ によって表現される理論を与える公理写像を

\[
\mathcal{T}:\mathcal{S}\longrightarrow\mathrm{Th}
\]

とする。

したがって、

\[
\mathcal{T}(s)
\]

は単に公理集合そのものを表すのではなく、Solver $s$ の
公理選択および推論規則・構成制約によって表現される理論を
表す。

一方、ECA における公理選択空間を

\[
I\subseteq\mathcal{P}(S)
\]

とし、その元 $i\in I$ を実際に採用され得る公理集合とする。

また、

\[
B(i)\subseteq i\subseteq S
\]

を満たす離散的要素集合 $B(i)$ を導入する。


\subsection{H.2 Solverの公理選択とECAの公理選択空間}

Solver $s\in\mathcal S$ に対して、その公理選択成分は
\[
\mathcal A_s
\]
である。

ここで、Solver の定義と ECA の公理選択空間 $I$ を接続するため、
次の適合条件を置く。

\begin{definition}[Solver--ECA適合条件]
Solver $s\in\mathcal S$ が ECA の公理選択空間 $I$ に適合するとは、

\[
\mathcal A_s\in I
\]

が成立することをいう。
\end{definition}

したがって、ECA に適合する Solver 全体を

\[
\mathcal S_I
:=
\left\{
s\in\mathcal S
\mid
\mathcal A_s\in I
\right\}
\]

と定義する。


\subsection{H.3 公理選択復元写像}

\begin{definition}[公理選択写像]
ECA に適合する Solver $s\in\mathcal S_I$ に対して、

\[
\mathfrak A:\mathcal S_I\longrightarrow I
\]

を

\[
\boxed{
\mathfrak A(s):=\mathcal A_s
}
\]

によって定義する。

以下、

\[
i_s:=\mathfrak A(s)=\mathcal A_s
\]

と記す。
\end{definition}

この定義により、公理選択 $i_s$ は外部から恣意的に
割り当てられるものではなく、Solver $s$ の内部構造
\[
s=(\mathcal A_s,\mathcal R_s)
\]
における公理選択成分から直接得られる。


\begin{proposition}[公理選択写像の存在]
\[
\mathfrak A:\mathcal S_I\longrightarrow I
\]
はwell-definedな写像である。
\end{proposition}

\begin{proof}
任意の
\[
s\in\mathcal S_I
\]
を取る。

$\mathcal S_I$ の定義より、

\[
\mathcal A_s\in I
\]

が成立する。

したがって、

\[
\mathfrak A(s):=\mathcal A_s
\]

は $I$ の元を与える。

また、Solver $s$ は

\[
s=(\mathcal A_s,\mathcal R_s)
\]

として定義されているため、同一の Solver $s$ に対する
$\mathcal A_s$ はその定義によって固定されている。

よって、

\[
\mathfrak A(s)=\mathcal A_s
\]

は各 $s\in\mathcal S_I$ に対して一意に定まり、

\[
\mathfrak A:\mathcal S_I\to I
\]

はwell-definedである。
\end{proof}


\subsection{H.4 $\mathcal{T}(s)$ と公理選択の関係}

Solver $s$ は

\[
s=(\mathcal A_s,\mathcal R_s)
\]

であるため、

\[
\mathcal T(s)
\]

はその公理選択 $\mathcal A_s$ と推論規則・構成制約
$\mathcal R_s$ によって決定される理論である。

したがって、

\[
\mathcal T(s)
=
\mathcal T(\mathcal A_s,\mathcal R_s)
\]

と表記できる。

ここで注意すべきなのは、

\[
\mathcal T(s)
\]

から公理集合を単純に集合論的な逆像として復元する必要はない
ということである。

Solver の定義そのものが

\[
s=(\mathcal A_s,\mathcal R_s)
\]

を与えているため、Solver の公理選択成分は

\[
\mathcal A_s
\]

として直接抽出できる。

したがって、

\[
\boxed{
\mathcal T(s)
\text{ が表現する理論に対応する公理選択}
=
\mathcal A_s
=
i_s
}
\]

として扱う。

これは、$\mathcal T(s)$ が公理選択そのものではなく、
Solver によって表現される理論であることを考慮した定式化である。


\subsection{H.5 公理選択写像のSolver同値性}

Solver 集合上の同値関係を

\[
s\sim_{\mathrm{Sol}}t
\]

とする。

Representation Independence により、Solver として同値な
二つの Solver は異なる内部表現を持つことが許される。

したがって、

\[
s\sim_{\mathrm{Sol}}t
\]

から必ずしも

\[
\mathcal A_s=\mathcal A_t
\]

を要求する必要はない。

そこで、公理選択空間 $I$ 上に同値関係

\[
\sim_I
\]

を導入し、

\[
\boxed{
s\sim_{\mathrm{Sol}}t
\Longrightarrow
\mathfrak A(s)\sim_I\mathfrak A(t)
}
\]

を要求する。

これは、Solver の内部表現が異なっていても、ECA における
公理選択の評価構造が保存されることを意味する。


\subsection{H.6 離散評価構造}

ECA において、任意の $i\in I$ に対して

\[
B(i)\subseteq i\subseteq S
\]

が成立する。

したがって、Solver $s\in\mathcal S_I$ に対応する

\[
i_s=\mathfrak A(s)
\]

について、

\[
B(i_s)\subseteq i_s\subseteq S
\]

が成立する。

\begin{definition}[Solverの離散評価構造]
Solver $s\in\mathcal S_I$ に対して、その離散評価構造を

\[
\boxed{
D_s:=B(i_s)=B(\mathfrak A(s))
}
\]

と定義する。
\end{definition}

この定義により、

\[
D_s\subseteq i_s\subseteq S
\]

が直ちに成立する。

さらに、$D_s$ が有限集合である場合、ECA の離散的評価式を
Solver $s$ に適用して、

\[
\boxed{
E_{\mathrm d}(s)
:=
\sum_{b\in D_s}w_s(b)
}
\]

と定義できる。

ここで重み関数

\[
w_s:S\longrightarrow[0,1]
\]

は

\[
\sum_{u\in S}w_s(u)=1
\]

を満たすものとする。

このとき、

\[
0\leq E_{\mathrm d}(s)\leq1
\]

が成立する。


\begin{proposition}[離散評価の有界性]
$D_s$ が有限または可算であり、

\[
w_s:S\to[0,1],
\qquad
\sum_{u\in S}w_s(u)=1
\]

を満たすならば、

\[
0\leq
E_{\mathrm d}(s)
\leq1
\]

である。
\end{proposition}

\begin{proof}
各 $b\in D_s$ に対して

\[
w_s(b)\geq0
\]

であるから、

\[
E_{\mathrm d}(s)
=
\sum_{b\in D_s}w_s(b)
\geq0.
\]

また、

\[
D_s\subseteq S
\]

であるため、

\[
\sum_{b\in D_s}w_s(b)
\leq
\sum_{u\in S}w_s(u)
=
1.
\]

したがって、

\[
0\leq E_{\mathrm d}(s)\leq1.
\]

\hfill$\square$
\end{proof}


\subsection{H.7 連続評価構造：測度そのもの}

Solver $s$ に対応する公理選択 $i_s$ 上で連続的評価を行うため、
測度

\[
\mu_s
\]

を導入する。

\begin{definition}[連続評価測度]
Solver $s$ に対して、連続評価に用いられる測度そのものを

\[
\boxed{
C_s^{(\mu)}:=\mu_s
}
\]

と定義する。

対応する連続評価値を

\[
\boxed{
E_{\mathrm c}(s)
:=
\mu_s(i_s)
=
\int_S
\mathbf 1_{i_s}(u)\,d\mu_s(u)
}
\]

とする。
\end{definition}

ここで

\[
\mathbf1_{i_s}:S\to\{0,1\}
\]

は $i_s$ の指示関数である。


\subsection{H.8 連続評価構造：測度空間}

測度そのものだけでは、可測性や測度の定義域を必要とする
場合に十分ではない。

したがって、可測空間および測度を含めて扱う必要がある場合には
次の定義を用いる。

\begin{definition}[連続評価測度空間]
Solver $s$ に対して、連続評価を成立させる測度空間を

\[
\boxed{
C_s^{(\mathrm{ms})}
:=
(I_s,\Sigma_{I_s},\mu_s)
}
\]

と定義する。

ここで、

\[
I_s
\]

は連続評価に用いられる公理選択空間、

\[
\Sigma_{I_s}
\]

は $I_s$ 上の $\sigma$-代数、

\[
\mu_s:\Sigma_{I_s}\to[0,1]
\]

は測度である。
\end{definition}

測度そのものを対象とする

\[
C_s^{(\mu)}
\]

と測度空間を対象とする

\[
C_s^{(\mathrm{ms})}
\]

は異なるレベルの構造を表す。

すなわち、

\[
C_s^{(\mu)}
\]

は評価作用そのものを、

\[
C_s^{(\mathrm{ms})}
\]

はその評価作用を成立させる測度論的構造全体を表す。


\subsection{H.9 測度と測度空間の関係}

測度空間

\[
C_s^{(\mathrm{ms})}
=
(I_s,\Sigma_{I_s},\mu_s)
\]

から第三成分を取り出す写像

\[
\pi_\mu:
C_s^{(\mathrm{ms})}
\longrightarrow
C_s^{(\mu)}
\]

を

\[
\pi_\mu
(I_s,\Sigma_{I_s},\mu_s)
=
\mu_s
\]

によって定義する。

したがって、

\[
C_s^{(\mathrm{ms})}
\longrightarrow
C_s^{(\mu)}
\]

という自然な忘却写像が存在する。

しかし、一般には

\[
\mu_s
\]

のみから

\[
(I_s,\Sigma_{I_s})
\]

を一意に復元することはできない。

したがって、

\[
\boxed{
C_s^{(\mu)}
\text{ は }C_s^{(\mathrm{ms})}
\text{ の情報を完全には保持しない}
}
\]

。


\subsection{H.10 離散評価と連続評価の統一}

Solver $s$ に対して、

\[
i_s=\mathfrak A(s)
\]

と置く。

離散評価は

\[
E_{\mathrm d}(s)
=
\sum_{b\in B(i_s)}w_s(b)
\]

であり、連続評価は

\[
E_{\mathrm c}(s)
=
\int_S
\mathbf1_{i_s}(u)\,d\mu_s(u)
\]

である。

したがって、

\[
\boxed{
\begin{aligned}
D_s
&=
B(i_s),
\\[1mm]
E_{\mathrm d}(s)
&=
\sum_{b\in D_s}w_s(b),
\\[1mm]
C_s^{(\mu)}
&=
\mu_s,
\\[1mm]
E_{\mathrm c}(s)
&=
\int_S\mathbf1_{i_s}(u)\,d\mu_s(u).
\end{aligned}
}
\]

という統一的な構成が得られる。

この構成において、離散式と連続式は別個の新しい評価法として
導入されたものではなく、ECA に既に定義された二つの表現を
Solver $s$ に適用したものである。


\subsection{H.11 中間Solverの厳密な定義}

\begin{definition}[中間Solver]
Solver $s\in\mathcal S_I$ が中間Solverであるとは、次の条件を
すべて満たすものをいう。

\begin{enumerate}
    \item
    公理選択
    \[
    i_s=\mathfrak A(s)=\mathcal A_s
    \]
    が存在する。

    \item
    離散評価構造
    \[
    D_s=B(i_s)
    \]
    が存在し、非自明な離散評価
    \[
    E_{\mathrm d}(s)
    =
    \sum_{b\in D_s}w_s(b)
    \]
    が定義される。

    \item
    連続評価測度
    \[
    C_s^{(\mu)}=\mu_s
    \]
    または連続評価測度空間
    \[
    C_s^{(\mathrm{ms})}
    =
    (I_s,\Sigma_{I_s},\mu_s)
    \]
    が存在する。

    \item
    一般解
    \[
    \mathcal G(s)
    \]
    が離散評価と連続評価の双方に非自明に依存する。
\end{enumerate}
\end{definition}


\subsection{H.12 一般解における二重評価構造}

(G) において定義された一般解

\[
\mathcal G:\mathcal S\longrightarrow X
\]

に対し、中間Solver $s$ では、

\[
\mathcal G(s)
=
\Phi_s
\left(
E_{\mathrm d}(s),
E_{\mathrm c}(s)
\right)
\]

と表現する。

ここで

\[
\Phi_s:
[0,1]\times[0,1]
\longrightarrow X
\]

は Solver $s$ に対応する一般解構成写像である。

離散評価への非自明な依存性を、

\[
\exists x_1,x_2,y\in[0,1]
\]

について

\[
x_1\neq x_2
\]

かつ

\[
\Phi_s(x_1,y)
\neq
\Phi_s(x_2,y)
\]

が成立することと定義する。

連続評価への非自明な依存性を、

\[
\exists x,y_1,y_2\in[0,1]
\]

について

\[
y_1\neq y_2
\]

かつ

\[
\Phi_s(x,y_1)
\neq
\Phi_s(x,y_2)
\]

が成立することと定義する。


\subsection{H.13 中間Solver構造定理}

\begin{theorem}[中間Solver構造定理]
$ s\in\mathcal S_I $ とする。

次の条件を仮定する。

\begin{enumerate}
    \item
    \[
    i_s=\mathfrak A(s)=\mathcal A_s\in I.
    \]

    \item
    \[
    D_s=B(i_s)
    \]
    が定義される。

    \item
    \[
    E_{\mathrm d}(s)
    =
    \sum_{b\in D_s}w_s(b)
    \]
    が定義される。

    \item
    \[
    E_{\mathrm c}(s)
    =
    \int_S\mathbf1_{i_s}(u)\,d\mu_s(u)
    \]
    が定義される。

    \item
    \[
    \mathcal G(s)
    =
    \Phi_s(E_{\mathrm d}(s),E_{\mathrm c}(s))
    \]
    と表現できる。
\end{enumerate}

このとき、$s$ が中間Solverであることと、

\[
\exists x_1\neq x_2,\ y
\]

について

\[
\Phi_s(x_1,y)
\neq
\Phi_s(x_2,y)
\]

が成立し、かつ

\[
\exists x,\ y_1\neq y_2
\]

について

\[
\Phi_s(x,y_1)
\neq
\Phi_s(x,y_2)
\]

が成立することは同値である。
\end{theorem}

\begin{proof}
定義 H.11 より、中間Solverでは一般解が離散評価と連続評価の
双方に非自明に依存する。

まず離散評価について、もし

\[
\Phi_s(x_1,y)=\Phi_s(x_2,y)
\]

が任意の $x_1,x_2,y\in[0,1]$ について成立するならば、
$\Phi_s$ は第1変数に依存しない。

したがって、ある写像

\[
\Psi_s:[0,1]\to X
\]

が存在して

\[
\Phi_s(x,y)=\Psi_s(y)
\]

となる。

この場合、

\[
\mathcal G(s)
=
\Psi_s(E_{\mathrm c}(s))
\]

であり、一般解は離散評価に依存しない。

したがって $s$ は中間Solverではない。

対偶より、中間Solverならば

\[
\exists x_1\neq x_2,\ y:
\quad
\Phi_s(x_1,y)
\neq
\Phi_s(x_2,y)
\]

が成立する。

連続評価についても同様である。

もし任意の $x,y_1,y_2\in[0,1]$ に対して

\[
\Phi_s(x,y_1)
=
\Phi_s(x,y_2)
\]

が成立するならば、$\Phi_s$ は第2変数に依存しない。

したがって、ある写像

\[
\Psi_s':[0,1]\to X
\]

が存在して

\[
\Phi_s(x,y)
=
\Psi_s'(x)
\]

となる。

この場合、

\[
\mathcal G(s)
=
\Psi_s'(E_{\mathrm d}(s))
\]

であり、一般解は連続評価に依存しない。

したがって $s$ は中間Solverではない。

よって中間Solverであるためには双方の非自明な依存性が必要である。

逆に、双方の非自明な依存性が成立すれば、定義 H.11 の
第4条件が成立する。

したがって、

\[
\boxed{
s\text{ が中間Solver}
\iff
\mathcal G(s)
\text{ が離散評価・連続評価の双方に非自明に依存する}
}
\]

が成立する。

\hfill$\square$
\end{proof}


\subsection{H.14 $\mathcal{T}(s)$、離散評価および連続評価の関係}

Solver $s$ に対して、

\[
s=(\mathcal A_s,\mathcal R_s)
\]

および

\[
\mathcal T(s)
=
\mathcal T(\mathcal A_s,\mathcal R_s)
\]

である。

したがって、

\[
\mathcal A_s=i_s
\]

を用いることにより、

\[
\mathcal T(s)
=
\mathcal T(i_s,\mathcal R_s)
\]

と表現できる。

この公理選択 $i_s$ に対して、

\[
D_s=B(i_s)
\]

が得られ、さらに

\[
E_{\mathrm d}(s)
=
\sum_{b\in B(i_s)}w_s(b)
\]

および

\[
E_{\mathrm c}(s)
=
\int_S\mathbf1_{i_s}(u)\,d\mu_s(u)
\]

が得られる。

従って、Solver の理論的内容は

\[
\boxed{
\mathcal T(s)
\longleftarrow
(i_s,\mathcal R_s)
}
\]

によって表現され、その公理選択成分 $i_s$ に対して

\[
\boxed{
i_s
\longrightarrow
B(i_s)
\longrightarrow
E_{\mathrm d}(s)
}
\]

および

\[
\boxed{
i_s
\longrightarrow
\mu_s
\longrightarrow
E_{\mathrm c}(s)
}
\]

という二つの評価経路が得られる。


\subsection{H.15 離散式と連続式の対応}

ECA の離散形式

\[
\mu(i)
=
\sum_{b\in B(i)}w(b)
\]

に $i=i_s$ を代入すると、

\[
\boxed{
\mu_s^{\mathrm d}(i_s)
=
\sum_{b\in B(i_s)}w_s(b)
}
\]

を得る。

一方、ECA の連続形式

\[
\mu(i)
=
\int_S\mathbf1_i(s)\,d\mu(s)
\]

に $i=i_s$ および $\mu=\mu_s$ を代入すると、

\[
\boxed{
\mu_s^{\mathrm c}(i_s)
=
\int_S
\mathbf1_{i_s}(u)\,
d\mu_s(u)
}
\]

を得る。

したがって、

\[
\boxed{
E_{\mathrm d}(s)
=
\mu_s^{\mathrm d}(i_s)
}
\]

および

\[
\boxed{
E_{\mathrm c}(s)
=
\mu_s^{\mathrm c}(i_s)
}
\]

である。

この二つの式は、新たな評価原理を導入するものではなく、
同一の公理選択 $i_s$ に対して ECA の離散表現と連続表現を
適用したものである。


\subsection{H.16 中間Solverの数学的意味}

以上から、中間Solverは単に

\[
\text{離散集合}\cup\text{連続集合}
\]

として定義されるものではない。

中間Solver $s$ においては、

\[
i_s=\mathcal A_s
\]

を起点として、

\[
D_s=B(i_s)
\]

という離散構造と、

\[
C_s^{(\mu)}=\mu_s
\]

または

\[
C_s^{(\mathrm{ms})}
=
(I_s,\Sigma_{I_s},\mu_s)
\]

という連続構造が構成される。

そして、

\[
E_{\mathrm d}(s)
=
\sum_{b\in D_s}w_s(b)
\]

および

\[
E_{\mathrm c}(s)
=
\int_S\mathbf1_{i_s}(u)\,d\mu_s(u)
\]

を介して、

\[
\mathcal G(s)
=
\Phi_s
\left(
E_{\mathrm d}(s),
E_{\mathrm c}(s)
\right)
\]

が得られる。

従って中間Solverの本質は、

\[
\boxed{
\text{同一のSolverに対して離散的評価構造と連続的評価構造が存在し、
その双方が一般解の決定に非自明に寄与すること}
}
\]

にある。


\subsection{H.17 本節で証明された範囲}

本節では、以下を厳密に示した。

\begin{enumerate}
    \item
    Solver の公理選択成分
    \[
    \mathcal A_s
    \]
    が ECA の公理選択空間 $I$ に属するならば、

    \[
    \mathfrak A(s):=\mathcal A_s
    \]

    により公理選択写像を直接構成できる。

    \item
    したがって、

    \[
    i_s=\mathfrak A(s)=\mathcal A_s
    \]

    が一意に定まる。

    \item
    ECA の既存定義から、

    \[
    D_s=B(i_s)
    \]

    を離散評価構造として構成できる。

    \item
    ECA の離散式から、

    \[
    E_{\mathrm d}(s)
    =
    \sum_{b\in D_s}w_s(b)
    \]

    が得られる。

    \item
    ECA の連続式から、

    \[
    E_{\mathrm c}(s)
    =
    \int_S
    \mathbf1_{i_s}(u)\,d\mu_s(u)
    \]

    が得られる。

    \item
    連続評価については、

    \[
    C_s^{(\mu)}=\mu_s
    \]

    と

    \[
    C_s^{(\mathrm{ms})}
    =
    (I_s,\Sigma_{I_s},\mu_s)
    \]

    を区別できる。

    \item
    一般解が両評価へ非自明に依存することと、
    Solver が中間Solverであることが同値である。
\end{enumerate}

ただし、本節で用いた

\[
\mathcal A_s\in I
\]

という ECA 適合条件そのものについては、Solver の一般定義
だけから自動的に従うとしたものではない。

したがって、より大きな理論体系においては、

\[
\boxed{
\mathcal S_I
=
\{s\in\mathcal S\mid\mathcal A_s\in I\}
}
\]

を ECA に適合する Solver 集合として明示的に扱うことができる。

この区別により、

\[
\mathcal T(s)
\]

が未定義となる Solver や、ECA の公理選択空間に属さない
Solver を無理に中間Solverの理論へ含めることを避けられる。


\subsection{H.18 まとめ}

本節の構成は、

\[
\boxed{
s=(\mathcal A_s,\mathcal R_s)
}
\]

から始まり、

\[
\boxed{
i_s=\mathfrak A(s)=\mathcal A_s
}
\]

を得て、

\[
\boxed{
D_s=B(i_s)
}
\]

および

\[
\boxed{
C_s^{(\mu)}=\mu_s
\quad\text{または}\quad
C_s^{(\mathrm{ms})}
=
(I_s,\Sigma_{I_s},\mu_s)
}
\]

を構成する。

さらに、

\[
\boxed{
E_{\mathrm d}(s)
=
\sum_{b\in D_s}w_s(b)
}
\]

および

\[
\boxed{
E_{\mathrm c}(s)
=
\int_S
\mathbf1_{i_s}(u)\,d\mu_s(u)
}
\]

を得て、

\[
\boxed{
\mathcal G(s)
=
\Phi_s
\left(
E_{\mathrm d}(s),
E_{\mathrm c}(s)
\right)
}
\]

と一般解へ接続する。

このとき、双方の評価が一般解に非自明に寄与する Solver を
中間Solverと定義する。

従って、

\[
\boxed{
\text{Solver}
\rightarrow
\text{公理選択}
\rightarrow
\text{離散・連続評価}
\rightarrow
\text{一般解}
}
\]

という構造が得られる。
